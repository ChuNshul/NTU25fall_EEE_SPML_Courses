## English

A curated repository of my personal study notes and exam review materials for the **MSc (Signal Processing & Machine Learning) - SPML** programme at **NTU EEE**, Class of 2025 Fall.

SPML is a highly specialized and intense programme covering both classic signal processing and modern machine learning. Sifting through hundreds of lecture slides during the finals period can be overwhelming. To save future juniors from the pain of summarizing scattered PPTs, I've organized and open-sourced my key review notes here.

### 📄 Included Files
*   **`5G.pdf`**: Key concepts of 5G physical layer, waveforms, and network architecture.
*   **`人工智能与数据挖掘.pdf`** (AI & Data Mining): Core algorithms, data preprocessing, and model evaluation.
*   **`数字信号处理.pdf`** (Digital Signal Processing): Foundational DSP theory, transforms, and filter design.
*   **`机器视觉.pdf`** (Machine Vision): Image processing fundamentals, feature extraction, and CNN/Transformer basics (EE6222).
*   **`系统分析.pdf`** (System Analysis): System modeling and analysis methods.
*   **`网络安全与区块链.pdf`** (Cybersecurity & Blockchain): Security principles and blockchain fundamentals.
*   **`视频信号处理.pdf`** (Video Signal Processing): Image/video compression standards (H.264/MPEG), and deep learning for video (EE6427).
*   **`遗传算法.pdf`** (Genetic Algorithms): GA principles, operators, and applications (EE6407).

### ✨ Features
*   **Complete Coverage**: Covers core modules from both Signal Processing and Machine Learning tracks.
*   **Organized & Structured**: Instead of messy slides, these notes distill the core concepts and formulas into clear, readable summaries.
*   **High-Yield Focus**: Highlights common pitfalls, must-know theorems, and typical exam problem types.
*   **Finals Savior**: Perfect for quick revision, concept checking, and last-minute finals preparation.

### 🚀 How to Use
1.  **Direct Download**: Click the PDF files above to view or download.
2.  **Revision**: Use them as a checklist to ensure you haven't missed any core concepts before the exam.
